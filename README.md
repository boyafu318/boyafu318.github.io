# Boya Fu — research portfolio

My personal website, exploring metacognition, learning, and human–AI interaction.

A static HTML, CSS, and JavaScript site: no installation, build step, API key, or paid service is required.

## Publish with GitHub Pages

1. Open [Settings → Pages](https://github.com/boyafu318/boyafu.github.io/settings/pages).
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Choose **main** and **/(root)**, then **Save**.
4. Wait for GitHub's Pages deployment to finish. The Pages settings will display the live address.

Because this repository is named `boyafu.github.io` and the account is `boyafu318`, it is a project site. Its expected address is `https://boyafu318.github.io/boyafu.github.io/`. This is an expected address, not confirmation of a successful deployment. The repository name does not need to change.

## Edit without installing anything

1. Open [content.js](content.js).
2. Click GitHub's pencil icon to edit.
3. Change the text inside the quotation marks, preserving the commas and quotation marks.
4. Click **Commit changes**.
5. Once Pages is enabled, changes on main will trigger another deployment.

| File | What to edit |
| --- | --- |
| `content.js` | Introduction, thesis summary, and main biography |
| `index.html` | Sections, project descriptions, navigation, status labels, and links |
| `style.css` | Colors, fonts, spacing, responsive layouts |
| `script.js` | Illustration and expandable thesis details |
| `.nojekyll` | Leave in place; tells Pages to serve the static files directly |

To add a new paragraph in HTML, use `<p>Your text here.</p>`.
To add a link, use `<a href="https://example.com">Link label</a>`.
Keep asset links relative (for example, `style.css`, not `/style.css`) so they work on the project URL.
